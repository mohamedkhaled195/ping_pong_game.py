# Ping Pong Game

A two-player classic Ping Pong game built in Python using the built-in `turtle` graphics module.

## Features
- Two-player real-time controls on a single screen (`800x600` window with a center divider).
- Smooth ball movement with bounce physics off the top/bottom walls and both paddles.
- Live score tracking at the top of the screen with automatic ball reset after each point.

## Controls
- **Player 1 (Blue):** `W` (Move Up), `S` (Move Down)
- **Player 2 (Red):** `Up Arrow` (Move Up), `Down Arrow` (Move Down)

## How to Run
1. Make sure **Python 3** is installed on your computer.
2. Download or clone this repository and open the folder in **PyCharm** (or any Python editor).
3. Run `ping_pong_game_2.py`.
